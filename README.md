# Pro Facility Management Website

Eine professionelle Website für Pro Facility Management - Ihr kompetenter Partner für professionelle Facility Management Lösungen.

## Leistungen

- Unterhaltsreinigung
- Teppichbodenreinigung
- Glasreinigung
- Industriereinigung
- Bauendreinigung
- Winterdienst
- Tiefgaragenreinigung / Parkhausreinigung
- Hausmeisterservice
- Entrümpelung
- Garten- und Grünflächenpflege

## 🚀 Website auf All-Inkl Server hochladen

**📖 WICHTIG:** Lesen Sie die Datei [WIE-HOCHLADEN.md](./WIE-HOCHLADEN.md) für eine ausführliche Schritt-für-Schritt-Anleitung!

### Schnellstart

\`\`\`bash
# 1. Pakete installieren
npm install

# 2. Website bauen (erstellt statische HTML-Dateien)
npm run build

# 3. Der 'out' Ordner enthält jetzt alle fertigen Dateien
# 4. Laden Sie den INHALT vom 'out' Ordner mit FileZilla hoch
\`\`\`

### Was wird erstellt?

Nach `npm run build` finden Sie im **`out`** Ordner:
- ✅ `index.html` - Ihre Startseite (wird automatisch geladen)
- ✅ Alle Unterseiten als HTML-Dateien
- ✅ CSS und JavaScript im `_next` Ordner
- ✅ Alle Bilder und Assets

**Wichtig:** Laden Sie **NUR den Inhalt** vom `out` Ordner auf Ihren Server hoch, nicht den Ordner selbst!

## Lokale Entwicklung

\`\`\`bash
# Dependencies installieren
npm install

# Development Server starten
npm run dev

# Öffnen Sie http://localhost:3000
\`\`\`

### Build für Produktion

\`\`\`bash
npm run build
npm start
\`\`\`

## 📤 Server-Anforderungen

- ✅ **Kein Node.js** auf dem Server nötig
- ✅ **Kein PHP** nötig
- ✅ Nur ein **statischer Webserver** (Apache, Nginx, etc.)
- ✅ Funktioniert auf All-Inkl, Strato, 1&1, Hostinger, etc.

Die Website wird in reine HTML/CSS/JavaScript-Dateien umgewandelt und kann auf jedem Standard-Webserver laufen.

## Technologie Stack

- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS v4
- **UI Components:** shadcn/ui
- **Icons:** Lucide React
